# Community health files

The shared contributing guide, security policy, code of conduct and issue forms for every
repository under this account. GitHub uses each file here for a public repository that does
not have its own copy.

| File | What it is for |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to report a problem, how fast we reply, pull requests, AI help |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability in private |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Issue forms: bug, Bluetooth device, feature request |
| [.github/pull_request_template.md](.github/pull_request_template.md) | The pull request checklist |

A repository that has its own copy of a file uses that copy instead.
