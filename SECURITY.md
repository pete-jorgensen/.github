# Security policy

These rules apply to every repository under this account that does not have its own
`SECURITY.md`.

## Supported versions

Only the latest release of each project gets security fixes. Where a project has no
releases, the default branch is the supported version.

## Reporting a vulnerability

Do not open a public issue for a security problem.

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability**. This opens a private advisory that only you and the
   maintainer can read.
3. Say what the problem is, which version has it, and how to reproduce it.

We reply within a week. We tell you when a fix is released, and we credit you in the advisory
unless you ask us not to.

For a fork, a problem that is also in the upstream project goes to the upstream project too.
Use its own security policy.
